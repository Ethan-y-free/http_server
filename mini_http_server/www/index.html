🚀 tiny-http

一个从零手写的高性能 C++ HTTP 服务器

✨ 功能特性

  • 主从 Reactor 架构（MainReactor + SubReactor）
  • Epoll ET 边缘触发 + 非阻塞 I/O
  • HTTP/1.1 长连接（Keep-Alive）
  • 状态机 HTTP 请求解析
  • 静态文件服务 + MIME 类型自动检测
  • 线程池异步处理
